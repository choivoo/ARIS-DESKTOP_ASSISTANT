# 한국어

## ARIS Desktop Assistant란?

**ARIS Desktop Assistant**는 Blue Archive의 아리스에서 영감을 받아 제작한
Windows용 로컬 데스크톱 어시스턴트 프로젝트입니다.

EP님의 영상을 보던 중 친척동생이 비슷한 프로그램을 만들어 달라고 해서
처음에는 바로 만들어주려고 했습니다.

그런데 만들기 직전에 문득,

**"잠깐, 나도 이런 거 직접 만들어보고 싶은데?"**

라는 생각이 들었습니다.

그래서 초등학교 6학년인 제가 ChatGPT와 함께 약 3일 동안 직접 개발했고,
그 결과 ARIS Desktop Assistant 4.2.0이 완성되었습니다.

단순한 캐릭터 창이 아니라 대화, 음성, 날씨, 웹 기능 등을 하나의
Windows 데스크톱 프로그램 안에서 사용할 수 있도록 만드는 것을 목표로 했습니다.

## ✨ 주요 기능

- 🌦️ 날씨 정보 확인
- 🌐 웹 관련 명령
- ▶️ YouTube 검색 및 실행
- 🧠 로컬 AI 기능
- 📦 Portable 패키지
- 🖥️ Windows 10 / 11 x64 지원

# English

## What is ARIS Desktop Assistant?

**ARIS Desktop Assistant** is a local Windows desktop assistant project
inspired by Aris from Blue Archive.

The project started while I was watching a video by EP.
My younger relative asked me to make something similar for them.

At first, I was going to build it right away.

Then I thought:

**"Wait... I want to make one for myself too."**

So, as a sixth-grade elementary school student, I developed the project
with ChatGPT over approximately three days.

That became **ARIS Desktop Assistant 4.2.0**.

The goal is to go beyond a simple desktop character and combine
conversation, voice synthesis, weather information, web commands,
character expressions and other assistant features into one Windows application.

## ✨ Features

- 💬 Natural-language conversations with ARIS
- 🇰🇷 Korean text input
- 🇯🇵 Korean → Japanese voice output
- 🔊 GPT-SoVITS based TTS
- 🎭 Character expressions and lip sync
- 🌦️ Weather information
- 🌐 Web commands
- ▶️ YouTube search and launch
- 🧠 Local AI functionality
- 📦 Portable distribution
- 🖥️ Windows 10 / 11 x64 support

## 📥 Download

Official download website:

https://aris-desktop-assistant-420.carums84.chatgpt.site/

You can also download the latest available build from the
**Releases** section of this GitHub repository.

Current stable version:

**ARIS Desktop Assistant 4.2.0**

## 💻 Installation

1. Download the latest ARIS Desktop Assistant ZIP package.
2. Fully extract the ZIP archive.
3. Move the extracted folder wherever you want.
4. Run the ARIS Desktop Assistant executable.
5. Wait for the initial startup process to complete.
6. Start talking with ARIS!

The Portable package contains the runtime and resources required by the application.

## ⚠️ Disclaimer

ARIS Desktop Assistant is an unofficial fan-made project.

It is not an official application of NEXON Games or Blue Archive.

Blue Archive, its characters, and related assets belong to their
respective rights holders.
